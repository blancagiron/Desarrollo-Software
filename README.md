Este repositorio contiene las prácticas desarrolladas en la asignatura Desarrollo de Software. En estas prácticas, trabajamos con distintos patrones de diseño aplicados a problemas reales, utilizando diversos lenguajes y herramientas de desarrollo.

Actualmente, el repositorio contiene la Práctica 1, en la que se exploran patrones creacionales y estructurales dentro de la Programación Orientada a Objetos (POO).
