# Práctica 2

Este repositorio contiene la segunda práctica de la asignatura Desarrollo del Software. En esta práctica, nos hemos centrado en la adaptación de software, la ampliación de funcionalidades, y la implementación de patrones arquitectónicos, utilizando Flutter. 

## Índice:

### 1. [Ejercicio 1. Mantenimiento del Sistema de Filtros](https://github.com/blancagiron/Desarrollo-Software/tree/master/P2/ejercicio1)
- Patrón usado: Filtros de Intercepción (adaptado a Flutter).
- Descripción: Migración y mejora del sistema de validación de email y contraseña implementado en la Práctica 1. Además, se ha añadido verificación de duplicados y sistema de notificaciones para indicar qué filtro ha fallado.
### 2. [Ejercicio 2. LLM en Flutter](https://github.com/blancagiron/Desarrollo-Software/tree/master/P2/ej2_grupal)
- Patrón usado: Strategy.
- Descripción: Aplicación Flutter que se conecta con la API de Hugging Face. El usuario puede seleccionar el modelo LLM desde la interfaz y obtener respuestas dinámicas según el mensaje ingresado.
