# Práctica 1

Este repositorio contiene la primera práctica de la asignatura Desarrollo del Software. En esta práctica, nos hemos centrado en la programación orientada a objetos (POO), implementando distintos patrones de diseño creacionales y estructurales en escenarios reales con Java y Python. 

## Índice:

### 1. [Ejercicio 1. Patrón Factorı́a Abstracta en Java](https://github.com/blancagiron/Desarrollo-Software/tree/master/P1/ej1)
- Patrón usado: Factoría Abstracta y Factory Method.
- Descripción: Simulación de carreras de bicicletas usando hebras en Java.
### 2. [Ejercicio 2. Patrón Decorator en Python](https://github.com/blancagiron/Desarrollo-Software/tree/master/P1/ej2)
- Patrón usado: Decorator.
- Descripción: Uso de la API de Hugging Face para generar resúmenes de texto, con posibilidad de añadir funcionalidad dinámica mediante decoradores.
### 3. [Ejercicio 3. Patrón Strategy](https://github.com/blancagiron/Desarrollo-Software/tree/master/P1/ej3)
- Patrón usado: Strategy
- Descripción: Web Scraping en [quotes.toscrape](https://quotes.toscrape.com/) usando dos estrategias distintas, BeautifulSoup y Selenium. 
### 4. [Ejercicio 4. Patrón Filtros de Intercepción](https://github.com/blancagiron/Desarrollo-Software/tree/master/P1/ej4)
- Patrón usado: Filtros de Intercepción
- Descripción: Implementación de un sistema de validación de credenciales mediante filtros encadenados. 

## Objetivos:
- Aplicar la POO en escenarios prácticos
- Aprender a usar patrones creacionales y estructurales para mejorar el diseño del código.
- Familiarizarnos con herramientas como Selenium, BeautifulSoup, Hugging Face, hebras en Java, etc.
- Tomar decisiones de diseño, eligiendo el patrón más adecuado en cada caso.
- Comprender cómo adaptar los patrones a distintos lenguajes de programación (Java/Python).
-  Usar herramientas como GitHub para la distribución de tareas y el trabajo cooperativo.

---

Esta práctica ha sido desarrollada en equipo, utilizando Git y GitHub como herramientas principales para la gestión del código, además de que nos ha ayudado a familiarizarnos con buenas prácticas en el desarrollo de software colaborativo.

Además, nos ha permitido consolidar nuestros conocimientos sobre la aplicación de patrones de diseño, ayudándonos a comprender cuándo y por qué utilizarlos. Gracias a ello, hemos aprendido a estructurar el código de forma modular y escalable, favoreciendo su mantenimiento y reutilización en proyectos futuros.
